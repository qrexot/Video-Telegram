# Video Telegram

Публичная видеотека для телефона и ПК. GitHub Pages размещает интерфейс из корня репозитория или папки `docs`. Каталог и просмотр доступны без входа. Для загрузки нужен аккаунт владельца в Supabase Auth. Файлы находятся в закрытом Telegram-канале. Поддерживаются MP4 и WebM объёмом до 2 ГБ (2 000 000 000 байт). Крупные файлы передаются частями, а плеер читает видео потоково.

## GitHub Pages

Публикация из ветки `main` поддерживает оба источника GitHub Pages (корень репозитория и `/docs`).

## Новый проект Supabase

1. В отдельном проекте выполните `supabase/schema.sql` и разверните функцию `video` из папки `supabase/functions/video`. Для загрузки она проверяет сессию Supabase Auth и роль владельца в `video_members`.
2. В `docs/config.js` укажите URL и публичный ключ именно этого проекта. В Auth выключите открытую регистрацию и вручную создайте аккаунт владельца с подтверждённой почтой.
3. Добавьте UUID этого аккаунта в таблицу `public.video_members` с ролью `owner`.

## Закрытый Telegram-канал

После входа владельца откройте «Telegram» в видеотеке. Если параметры канала уже заданы, запросите код и подтвердите вход там же.

Для ручной настройки используйте Telegram-аккаунт и его собственные API ID и API Hash. В папке проекта запустите команду через Deno 2.

```sh
deno run --allow-net --allow-env --allow-read --allow-write=telegram-secrets.env --allow-sys tools/telegram-setup.ts
```

Подтвердите вход в Telegram прямо в терминале. Укажите название своего закрытого канала или нажмите Enter для создания нового. Скрипт сохранит файл `telegram-secrets.env`. Загрузите его в секреты Edge Functions проекта видеотеки.

```sh
supabase secrets set --project-ref <НОВЫЙ_PROJECT_REF> --env-file telegram-secrets.env
```

Затем войдите на сайт аккаунтом владельца, загрузите небольшой MP4 и откройте его из каталога. Для стабильного воспроизведения на разных устройствах используйте MP4 с H.264 и AAC.

## Качество воспроизведения

Плеер предлагает оригинал и опубликованные копии 360p, 480p, 720p, 1080p и 2160p. Для новых видео владелец может добавить подготовленную копию через плеер. Для быстрого старта MP4 сохраняйте с индексом в начале файла (`ffmpeg -movflags +faststart`).

## Библиотека фото и обложки

Примените миграции `20261119224000_media_library.sql` и `20261119230000_telegram_photo_storage.sql` к существующей базе. Фотооригиналы, превью и обложки хранятся файлами в закрытом Telegram-канале. Supabase хранит карточки и идентификаторы сообщений. Для просмотра сайт использует JPEG-превью, а при скачивании отдаёт исходные байты. Обложки видео создаются при загрузке на устройстве владельца. Если устройство не декодирует видео, обложку можно выбрать в плеере. Скрытые материалы и корзина доступны владельцу.

## Публикация из Telegram

Отправьте фото или видео в подключённый Telegram-канал. Сервер проверяет новые посты каждые 30 секунд, добавляет карточки и дописывает ID в подписи. Если в подписи несколько строк, первая станет названием, а остальные — описанием. В интерфейсе владельца название и описание можно изменить через «Изменить». Подпись в Telegram обновится при следующей синхронизации.

Чтобы сохранить исходное качество фотографии, отправьте её в Telegram как файл. На сайте для скачивания доступна версия, которую принял Telegram. Если Telegram оставил у фото только оригинал, фоновая задача сохранит отдельное JPEG-превью размером до 1000 пикселей по длинной стороне прямо в Telegram. Совместимость видео соответствует MP4 и WebM. Для реплик на другом проекте укажите URL этого проекта в миграции расписания.
