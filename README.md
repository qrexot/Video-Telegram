# Video Telegram

Закрытая видеотека для телефона и ПК. GitHub Pages размещает интерфейс из корня репозитория или папки `docs`. Supabase хранит каталог и выдаёт доступ. Файлы находятся в закрытом Telegram-канале. Первая версия поддерживает MP4 и WebM объёмом до 20 МБ. Плеер получает файл целиком и затем воспроизводит его локально.

## GitHub Pages

В **Settings → Pages** публикация из ветки `main` поддерживает оба источника: `/ (root)` и `/docs`.

## Новый проект Supabase

1. В отдельном проекте выполните `supabase/schema.sql` и разверните функцию `video` из папки `supabase/functions/video`. Она проверяет сессию через Supabase Auth и членство в `video_members` для каждого запроса.
2. В `docs/config.js` укажите URL и публичный ключ именно этого проекта. В Auth выключите открытую регистрацию и вручную создайте аккаунт владельца с подтверждённой почтой.
3. Добавьте UUID этого аккаунта в таблицу `public.video_members` с ролью `owner`. Для просмотра выдавайте отдельным аккаунтам роль `viewer`.

## Закрытый Telegram-канал

Для подключения используйте отдельный Telegram-аккаунт и его собственные API ID и API Hash. В папке проекта запустите команду через Deno 2.

```sh
deno run --allow-net --allow-env --allow-read --allow-write=telegram-secrets.env --allow-sys tools/telegram-setup.ts
```

Введите код и пароль прямо в терминале. Скрипт создаст закрытый канал и файл `telegram-secrets.env`. Загружайте его только в секреты Edge Functions нового проекта.

```sh
supabase secrets set --project-ref <НОВЫЙ_PROJECT_REF> --env-file telegram-secrets.env
```

Затем войдите на сайт аккаунтом владельца, загрузите небольшой MP4 и откройте его из каталога. Для стабильного воспроизведения на разных устройствах используйте MP4 с H.264 и AAC.
